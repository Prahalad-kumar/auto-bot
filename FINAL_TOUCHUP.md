# AUTO-BOT final touch-up

This package preserves the complete original source tree. The backtest UI now shows option contracts grouped by expiry with clear strike, CE/PE and lot-size information. ATM mode resolves one nearest ATM strike and runs both CE and PE. Backtest results include a contract summary and a detailed trade ledger with expiry, strike, entry/exit timestamps and prices, lots, quantity, stop, target, exit reason, charges and net P&L.

The original `.env` and repository files are preserved because this archive is intended as a full project handoff. Do not publish `.env` or real broker credentials.
